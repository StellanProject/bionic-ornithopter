<h3>它是什么</h3>
<p>ORNI-X 是一台能真正"飞起来"的仿生扑翼无人机实时仿真：无刷电机经 26:1 减速带动曲柄摇杆四连杆，把连续旋转变成上下扑动；两片柔性翼膜每一刻都用叶素理论逐段计算升力与阻力，合力与合力矩再注入 cannon-es 六自由度刚体，反过来决定姿态和轨迹。画面里的每个角度、每次抖动都是解方程解出来的，没有预录动画。</p>

<h3>为什么是无刷电机</h3>
<p>扑翼需要数千到一万多 rpm 的连续高转速（本模型空载上限约 15540 rpm）和几十瓦级的功率。步进电机开环、低速、转矩随转速骤降，既追不上 26:1 减速后的目标扑动频率，也无法在气动冲击负载下保持相位。这里用三相无刷直流电机（BLDC）加电调六步换向，按 <code>A+B- → A+C- → B+C- → B+A- → C+A- → C+B-</code> 六个扇区轮流导通。模型用准静态电流解 <code>I = (D·Vbus − ω/Kv)/R</code> 和 <code>T = I/Kv_rad</code>：油门越大电流越大，转速越高反电动势越大；电池内阻让母线电压随电流跌落，铜损让电机升温。电机的负载不是常数，而是气动力对扑动轴的力矩经四连杆速度比折算到曲柄的结果——所以风越大、桨距越"兜风"，电流就越大、转速就越掉。</p>

<h3>四连杆与"被动扭转"</h3>
<p>曲柄、连杆、摇杆、机架构成满足 Grashof 条件的曲柄摇杆机构，摇杆摆角 ψ 由闭式解给出，翼根转角 <code>φ = k·(ψ − ψ₀)</code>。真正的关键是桨距角：它由归一化扑动角速度驱动——下扑时翼面接近水平（约 15°）"兜风"产生升力，上扑时翻到约 90° 的"刀锋"切气减小阻力。四连杆的下扑/上扑速度并不对称，所以下扑桨距最低只到约 15°，上扑却能翻到 90°，这正是机构"急回"特性的体现。冲程平面再向前倾斜约 3.4°，让下扑路径后掠，周期平均就出现向前的推力。</p>

<h3>气动与风的耦合</h3>
<p>翼面沿展向切成 9 段。每段的相对风 = 机体速度 + 角速度×力臂 + 扑动/扭转速度 − 风速，投影到弦向/法向平面得到迎角 α，再用"线性段 + Viterna 失速后延伸"的极曲线取 CL、CD，用法向/切向分解 <code>F = qS(Fn·n + Fd·d)</code> 积分成整翼的力与力矩；这种写法在 α=±90° 处没有奇点。风同时改变升力、推力、阻力和电机负载，所以风速既是扰动，也是功耗来源。</p>

<h3>怎么玩</h3>
<ul>
<li><b>三种模式</b>：悬停辅助（定高 + 姿态增稳，适合观察配平）、自由飞行（切断辅助，纯物理，会翻滚）、系留测试（把机体锁在台架上，直接读升力/推力）。</li>
<li><b>左侧滑杆</b>：动力（油门、目标高度、KV、电池节数、减速比）、机构（冲程倾角、中位桨距、桨距摆幅、翻转锐度、俯仰相位、展向柔性）、环境（风速、风向、阵风强度、空气密度）、仿真时间倍率。</li>
<li><b>底部按钮</b>：起飞、风场（0→3→6→9 m/s 循环）、力矢量、机构透视，以及环绕/跟随/机构特写/气动侧视四种视角、暂停与重置。</li>
<li><b>快捷键</b>：<code>W/S</code> 悬停时调目标高度、其他模式调油门；<code>A/D</code> 滚转；<code>↑/↓</code> 俯仰；<code>Q/E</code> 偏航；<code>空格</code> 暂停；<code>R</code> 重置；<code>H</code> 帮助；<code>V</code> 力矢量；<code>C</code> 机构透视；<code>1/2/3</code> 切换三种模式。</li>
</ul>

<h3>看什么</h3>
<p>打开"力矢量"看 LIFT、THRUST、DRAG 与重力 W 如何平衡；看翼尖拖出的 8 字轨迹，它同时包含扑动与扭转；右侧极曲线的光点会在失速区与线性区之间来回跳——扑翼正是靠周期性地越过失速来换取升力。示波器展示三相电流与 ESC 占空比。建议先悬停观察 L/W 越过 1，再调"俯仰相位"和"冲程倾角"观察推力变化，最后加风看电流与姿态如何被扰动。</p>
<h3>翼型：固定膜翼 / 上扑折叠翼</h3>
<p>左侧"扑动机构"卡片顶部可以在两种翼型之间切换。默认的<b>折叠翼</b>在<b>上扑</b>阶段会按上扑角速度收拢翼面：
翼展沿展向收缩（翼尖最多收缩 55%），翼尖同时额外上卷，等效就是把"迎风面积"变小——这正是鸟类和果蝇上扑时的动作。</p>
<ul>
<li><b>为什么能省功</b>：下扑(功率冲程)时翼面完全展开、以近似 90° 迎角兜风，升力几乎全部来自这一段；
上扑(回程)时如果翼面仍然展开，就会白白产生向下的负升力和阻力。收拢后上扑段的阻力功率从约 5 W 降到 1 W 量级。</li>
<li><b>代价</b>：折叠是运动学调度的（由归一化扑动角速度驱动，<code>fold = k·smoothstep(−φ̇/0.45)</code>），
并不是独立伺服；收拢瞬间翼面会有一个轻微的"甩"动作，这也是真实柔性翼的现象。</li>
<li><b>怎么调</b>：<code>上扑折叠量</code> 0~90% 控制最大收缩比例（0 等价于固定翼）；<code>折叠翼尖上卷</code> 控制收缩时翼尖的额外上卷幅度。
把折叠量调到 0、或切到"固定膜翼"，就能对比两种翼型的升力/功率差异——注意观察右下角"上扑折叠"读数与电流变化。</li>
</ul>
