## 1. 坐标系、状态量与单位

### 1.1 坐标系约定

| 坐标系 | 轴向 | 用途 |
| --- | --- | --- |
| 世界系 W | +y 向上，重力 −9.81 m/s²；x-z 为水平面 | cannon-es 刚体积分、地面、风场、相机 |
| 机体系 B | +x 向前（机头），+y 向上（机背），+z 向右翼 | 气动、机构运动学、电机负载、遥测力分解 |

机体系的右手性：`x × y = z`。右翼沿 +z 展开，左翼沿 −z；翼面的弦向单位矢量为
`e_chord = A·[−1,0,0]`（由后缘指向前缘反方向，即 +x 的反向），法向为
`e_normal = e_chord × e_span`。翼根位置相对质心为 `[0, rootY, ±rootZ]`。

刚体姿态用四元数存储，遥测显示时转换为 `YXZ` 欧拉角：`pitch` 绕 x、`yaw` 绕 y、
`roll` 绕 z。**注意**：这里的"俯仰"指机体抬头/低头，而翼面的"桨距角"`theta` 是
翼面绕自身展向轴的几何安装角，两者不是同一个量。

### 1.2 主要状态量

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| `p, v` | 质心位置、速度（世界系存储，机体系参与气动计算） | m, m/s |
| `q, omega` | 姿态四元数、机体角速度 | —, rad/s |
| `theta_crank` | 曲柄角（0..2pi，循环回绕） | rad |
| `omega_crank` | 曲柄角速度 | rad/s |
| `phi, theta` | 翼根扑动角、翼面桨距角 | rad |
| `I, V_bus, T_m` | 电机相电流、母线电压、电机温度 | A, V, °C |
| `SOC` | 电池荷电状态 | 0..1 |

### 1.3 单位制

全部采用 SI：长度 m、质量 kg、时间 s、力 N、力矩 N·m、角度 rad（显示为 °）、
电压 V、电流 A、功率 W、温度 °C。`KV` 用工程惯例 rpm/V，进入模型前统一换算为
rad/s/V。

## 2. 六自由度刚体动力学

### 2.1 刚体方程

机体被视为质量 `m = 0.40` kg、惯量张量为对角阵
`I_b = diag(0.022, 0.032, 0.024)` kg·m² 的刚体（x 前向、y 垂向、z 展向）。
其平动与转动方程为

```text
m (dv/dt + omega × v) = F_B
I_b d(omega)/dt + omega × (I_b omega) = M_B
```

其中 `F_B`、`M_B` 是机体系下汇总的气动力、尾翼力、机体阻力与操纵力矩；
重力由 cannon-es 世界统一施加。`sim.js` 在每个物理步内：

1. 由 cannon-es 刚体读出世界系速度与角速度，用姿态四元数的逆变换转到机体系；
2. 把世界风矢量也转到机体系，供叶素与尾翼使用；
3. 在机体系累加 `F_B`、`M_B`（含翼面、尾翼、机体阻力）；
4. 再用四元数把合力/合力矩转回世界系写入 `body.force`、`body.torque`；
5. 调用 `world.step(dt)` 完成积分，同时推进电机/传动状态；
6. 处理系留模式、地面接触与遥测平滑。

> cannon-es 内部以世界系积分四元数与速度，因此"机体系列方程"在这里体现为
> 力的建模与分解，而不是直接把 Euler 方程交给求解器。两种写法在数学上等价，
> 但前者能方便地复用世界系碰撞检测。

### 2.2 力与力矩来源

| 来源 | 作用点/参考 | 说明 |
| --- | --- | --- |
| 左右翼 9 段叶素 | 各段 1/4 弦点 `pos` | 产生升力、推力、滚转/俯仰/偏航力矩 |
| 平尾 HT | `(-0.34, 0.01, 0)`，面积 0.021 m² | 升降舵偏转 ±0.38 rad |
| 垂尾 VT | `(-0.34, 0.05, 0)`，面积 0.014 m² | 方向舵偏转 ±0.34 rad |
| 机体等效阻力 | 质心 | 三轴阻力面积 `[0.011, 0.032, 0.030]` m²，`C_D = 0.55` |
| 重力 | 质心 | 世界系 `(0, -9.81, 0)` m/s² |
| 地面接触 | 机体包围盒 | 平面摩擦 0.45、恢复系数 0.18 |
| 悬停辅助力矩 | 质心 | 仅 `hover + assist` 模式启用 |

机体阻力按各轴独立二次律建模：

```text
F_drag,i = -0.5 * rho * C_D * A_i * v_rel,i * |v_rel,i|,   i = x,y,z
```

其中 `v_rel = v_B - wind_B`。该式在小迎角下近似为线性阻尼，在大速度下自动进入二次阻力。
以 `rho = 1.225`、`C_D = 0.55` 计算，5 m/s 时三轴阻力约为 0.093 N（x）、
0.270 N（y）、0.253 N（z）；可见机体在高速时的主要阻力来自侧面与垂向面积。

### 2.3 刚体与求解器参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 质量 | 0.40 kg | `config.params.mass` |
| 转动惯量 | 0.022 / 0.032 / 0.024 kg·m² | x / y / z |
| 碰撞体 | 半尺寸 0.17 × 0.06 × 0.075 m 的 Box | 仅用于地面/接触，不参与气动 |
| 初始高度 | 1.7 m | `reset(alt=1.7)` |
| 线性阻尼 | 0.015 | cannon-es `linearDamping` |
| 角阻尼 | 0.02 | cannon-es `angularDamping` |
| 求解器迭代 | 12 | `solver.iterations` |
| 宽相 | SAPBroadphase | — |
| 允许休眠 | 否 | 扑翼持续激励，休眠会丢失响应 |
| 地面摩擦/恢复 | 0.45 / 0.18 | — |
| 最低高度钳位 | 0.06 m，反弹系数 −0.2 | 防止地面穿透后数值发散 |

`0.022/0.032/0.024` 的量级说明：质量 0.4 kg、半展长 0.55 m 的扑翼机，绕展向（z）
的惯量主要来自翼面质量与机身分布，0.024 kg·m² 与均质细杆近似
`m L^2/12 ≈ 0.4 × 1.1^2/12 = 0.040` 同量级但偏小，符合"质量集中在机身、翼面较轻"的布局。
惯量直接决定滚转/俯仰角加速度，是姿态增稳增益整定的基准。

### 2.4 三种飞行模式

| 模式 | 行为 | 实现要点 |
| --- | --- | --- |
| `hover` 悬停辅助 | 高度保持 + 姿态增稳 | 油门由高度 PI 回路给出；俯仰/滚转由 PD + 积分力矩稳定 |
| `free` 自由飞行 | 油门、俯仰、滚转、偏航全部手动 | 升降舵/方向舵 + 左右翼差动扑动（`rollTrim`） |
| `tether` 系留测试 | 位置、姿态锁死 | 便于观察机构与气动，不产生自由飞行动力学 |

悬停辅助的高度回路（`sim.js`）：

```text
vy_cmd = clamp(1.15 * (altTarget - alt), -1.1, 1.1)
err    = vy_cmd - vy
altInt = clamp(altInt + 0.9 * err * dt, -0.35, 0.35)
thr    = clamp(0.72 + 0.085 * err + 0.16 * altInt, 0.18, 1.0)
```

姿态回路（俯仰/滚转）的目标角为 `pitchCmd = 0.30 * input.pitch`、
`rollCmd = 0.42 * input.roll`，PD 增益 `k_p = 3.2`、`k_d = 0.42`，积分增益 1.1，
积分限幅 ±0.55。偏航只做阻尼（0.55 比例 + 0.30 阻尼），不强制航向。
这些增益属于"控制参数"而非物理参数，改动会直接影响手感与稳定性。

### 2.5 姿态、角速度与显示平滑

遥测中的姿态角由四元数按 `YXZ` 顺序解算；力、俯仰角、滚转角用一阶低通平滑：

```text
alpha_s = 1 - exp(-dt / 0.10)
x_s   <- lerp(x_s, x, alpha_s)
```

即时间常数 0.10 s。这样 HUD 数值不会随 240 Hz 的扑动载荷剧烈跳动，但会带来约
0.1 s 的视觉延迟。物理积分本身没有这个平滑。

## 3. 动力系统：为什么是 BLDC，而不是步进电机

### 3.1 工程选型对比

扑翼机的动力需求与多旋翼不同：负载是**周期性、带惯性反冲的往复力矩**，转速需要
在 0 到约 10 Hz 扑动频率之间快速调节，且功率重量比直接决定能否起飞。两类电机的
差异如下：

| 维度 | 三相无刷直流电机（BLDC）+ ESC | 步进电机 |
| --- | --- | --- |
| 转矩密度 | 永磁转子，单位质量转矩高 | 铁芯/绕组占比大，转矩密度低 |
| 高速能力 | 反电动势与转速成正比，可到万转/分 | 转矩随频率迅速下降，高速易失步 |
| 效率 | 电流≈转矩，轻载损耗小 | 常以额定电流励磁，轻载也发热 |
| 控制方式 | 六步换向/矢量控制，闭环或传感器换向 | 开环脉冲 + 细分，位置可信但动态受限 |
| 过载能力 | 短时过载能力强，可承受气动冲击 | 过载即失步，无转矩储备 |
| 转子惯量 | 小（本例 5×10⁻⁶ kg·m²） | 通常显著更大 |
| 失效模式 | 堵转限流、过热 | 丢步（位置误差累积） |
| 驱动器 | 三相逆变桥，六步换向逻辑简单 | 需要脉冲/方向与细分驱动 |

对扑翼机而言，决定性因素是：**功率密度、转速上限、以及气动冲击负载下的转矩储备**。
步进电机在开环下无法感知失步，而扑翼的负载力矩每半个扑动周期就会剧烈变化；一旦
失步，翼面相位与气动力立即错乱。BLDC 的转矩与电流近似成正比，配合 ESC 限流可以
把"堵转/突风"转化为可控的电流峰值，这正是本模型选择 BLDC 的原因。

### 3.2 准静态电-机模型

源码（`drivetrain.js`）不模拟相电感与 PWM 开关细节，而是采用**准静态电流解**：
电枢电气时间常数远小于机械/扑动时间常数，电流在每个物理步内近似瞬时平衡。

```text
KV_rad = KV * 2*pi/60                 [rad/s/V]      // 900 rpm/V  -> 94.2478
K_t    = 1 / KV_rad                   [N*m/A]        // 6.82093e-3
omega_m = G * omega_crank             [rad/s]        // 电机轴转速，G = 26
emf    = omega_m / KV_rad             [V]
V_bus  = max(0.5, V_open(SOC) - I_prev * R_pack)
I      = clamp((D * V_bus - emf) / R_phase, -0.35*I_lim, I_lim)
T_m    = K_t * I                      [N*m]
T_crank = G * eta * T_m               [N*m]          // eta = 0.86
```

其中 `D` 为 ESC 油门（占空比指令，0..1），`R_phase = 0.090` Ω，`I_lim = min(26, 24) = 24` A（电机 26 A 与电池 24 A 取小）。负电流下限为
`-0.35 * 24 = -8.4` A，表示允许有限回馈/制动，但不允许无限倒灌。

由 `K_t = 1/KV_rad` 可知反电动势与转矩常数在 SI 下严格对应；这是 BLDC 建模的基本
一致性条件，也是"电功率 ≥ 机械功率"的物理基础。

### 3.3 六步换向（而不是正弦/矢量控制）

电机为 14 极 9 槽（`poles=14, slots=9`），极对数为 7。机械角到电气角的关系为

```text
theta_e = (poles/2) * theta_m = 7 * theta_m
sector  = floor( ((theta_e mod 2*pi) / (pi/3)) ) mod 6
```

每 60° 电气角换一次相，六个扇区依次为：

| 扇区 | 导通相 | 扇区 | 导通相 |
| --- | --- | --- | --- |
| 0 | A+ B− | 3 | B+ A− |
| 1 | A+ C− | 4 | C+ A− |
| 2 | B+ C− | 5 | C+ B− |

实现上只记录扇区序号用于 HUD 与示波器（`SECTORS` 数组），并不改变电流方程——
六步换向的电压利用率、转矩脉动等细节被"准静态平均电流"吸收。物理上六步换向的
转矩存在 6 倍电气频率的脉动；本模型不显式建模该脉动，原因见第 3.6 节的模型边界。

PWM 频率 8 kHz 远高于扑动频率（约 10 Hz）与电气时间常数倒数，因此用平均占空比
`D` 代替开关波形是合理的。9 槽/14 极组合的齿槽转矩较小、绕组系数较高，是航模
外转子电机的常见选择。

### 3.4 电池、母线电压与 SOC

3S 电池组，标称 `3 × 3.70 = 11.1` V，容量 900 mAh，内阻 0.028 Ω，
最大放电 24 A。开路电压随 SOC 线性变化：

```text
V_open(SOC) = cells * (3.30 + 0.40 * SOC)   // SOC=1 -> 11.1 V, SOC=0 -> 9.9 V
V_bus       = max(0.5, V_open - I * R_pack)
```

电流积分得到已用电量，进而更新 SOC：

```text
Ah_used += I * dt / 3600
SOC      = clamp(1 - Ah_used / 0.9, 0, 1)
```

母线电压随负载电流下降（"电压塌陷"），这会反馈到电流方程，形成电气-机械耦合：
大电流 → 母线电压下降 → 同样占空比下驱动电压下降 → 电流被自然抑制。这是电池
内阻对功率输出的实际限制，也是 3S 电池在 20 A 以上时"越飞越软"的原因。

### 3.5 热模型

电机温升用一阶热网络：

```text
P_loss = 1.5 * I^2 * (R_phase / 2) = 0.75 * I^2 * R_phase
C_th   = tau_thermal / R_th = 22 / 2.4 = 9.1667 J/K
dT/dt  = (P_loss - (T - 25) / R_th) / C_th
```

稳态温升 `DeltaT_ss = P_loss * R_th`。按该式估算：

| 持续电流 | 铜损 P_loss | 稳态温升 | 稳态温度（25 °C 环境） |
| --- | --- | --- | --- |
| 10 A | 6.75 W | 16.2 K | 41.2 °C |
| 15 A | 15.19 W | 36.4 K | 61.4 °C |
| 20 A | 27.0 W | 64.8 K | 89.8 °C |
| 24 A（限流点） | 38.88 W | 93.3 K | 118.3 °C |

可以看到：24 A 只能作为短时峰值，持续 24 A 会使稳态温度超过 `tempMax = 95` °C。
热时间常数 22 s 意味着大电流冲击后温度上升有明显滞后，短时过载是安全的；这也是
ESC 限流（而不是长时间恒流）的工程依据。`tempMax` 目前作为保护/显示阈值保留。

### 3.6 模型边界

- 未建模相电感、反电动势谐波、PWM 纹波、死区与开关损耗；
- 未建模磁饱和、铁损、齿槽转矩与六步换向的瞬时转矩脉动；
- 热模型用 0.75·I²R 近似六步换向的平均铜损（两相导通、每相导通 2/3 周期），
  与电气方程中的 I²R 不完全闭合，属于工程近似；
- `battery.sagK` 为界面预留参数，当前电-机模型使用内阻 `R_pack` 计算压降。

## 4. 减速比与折算惯量

### 4.1 减速传动变换

曲柄轴与电机轴之间为 26:1 减速（`gear=26`），传动效率 `eta=0.86`（模型把同步带/齿轮与轴承损失集中为一个效率项）：

```text
omega_m = G * omega_crank
T_crank = eta * G * T_m
P_crank = eta * P_motor_shaft = eta * T_m * omega_m
```

减速比把电机的高转速、低转矩转换为曲柄的低转速、高转矩；代价是转速降低 26 倍、
惯量按 `G^2` 折算放大。效率 0.86 表示 14% 的机械功率在减速传动与轴承中耗散（本模型将其作为集中损失，
不区分齿面/带面摩擦与轴承损失）。

### 4.2 曲柄轴等效惯量

对曲柄轴列转动方程时，所有随曲柄旋转或随扑动运动的惯量都要折算：

```text
J_eq(theta) = J_link + J_wing * (dphi/dtheta)^2 + G^2 * J_rotor
```

其中：

- `J_wing = 2 * m_w * span^2 / 3 = 2 * 0.034 * 0.55^2 / 3 = 6.8567e-3` kg·m²
  （两侧翼面按均质细杆/三角形分布的近似；系数 2 表示左右两翼）；
- `G^2 * J_rotor = 26^2 * 5.0e-6 = 3.38e-3` kg·m²；
- `J_link = 1.2e-4` kg·m²。

派生的数值：

| 工况 | `(dphi/dtheta)^2` | `J_eq` (kg·m²) |
| --- | --- | --- |
| 曲柄匀速、忽略扑动速度 | 0 | 1.0357e-2 |
| 扑动最快（`|dphi/dtheta| = 1.4567`） | 2.122 | 1.8050e-2 |
| 一个周期均值（ω=40 rad/s 工况） | 0.4701 | 6.724e-3（含机构项） |

**注意**：上表第三行是"周期平均"的等效值，仅用于估算平均加速能力；瞬态计算必须
用随曲柄角变化的 `J_eq(theta)`。源码在 `drivetrain.step` 中每步用当前
`dFlap` 重新计算。

### 4.3 转速、转矩与摩擦

空载曲柄转速（母线 11.1 V、不计损耗）：

```text
omega_crank,max = V_nom * KV_rad / G = 11.1 * 146.6077 / 26 = 62.59 rad/s = 9.96 Hz
```

源码另加 2% 的数值上限（`wMax`），即 10.16 Hz，防止数值发散。这是"电机反电动势
决定的物理上限"：转速再高，反电动势超过母线电压，电流反向，电机进入发电状态。

最大电流 24 A 时：

```text
T_m,max = K_t * 24 = 0.1637 N*m
T_crank,max = 26 * 0.86 * 0.1637 = 3.66 N*m
```

曲柄轴摩擦为粘性 + 库仑组合：`T_f = 0.004 * omega_crank + 0.020`（当
`omega_crank > 0.2` 时库仑项生效）。在 40 rad/s 时约 0.18 N·m，对应 7.2 W 的
摩擦功率，不能忽略。

### 4.4 减速比的选择

减速比的决定因素是"在目标扑动频率下，电机工作点接近额定转速且转矩有裕度"：

- 减速比过小：电机转速上不去或工作在低占空比，电流纹波/效率变差；
- 减速比过大：曲柄转速不足，且反射惯量 `G^2 J_rotor` 迅速增大，动态响应变慢；
- 26:1 使空载扑动频率约 10 Hz，覆盖 0.7–1.0 油门下的可用升力区间（按整机阻力与尾翼负载约 6–8.5 Hz），
  同时把 5×10⁻⁶ kg·m² 的转子惯量放大到 3.38×10⁻³ kg·m²，与翼面惯量同量级，
  属于"惯量匹配"较好的折中。

## 5. 扑翼运动学：曲柄摇杆四连杆

### 5.1 机构几何与闭式解

机构为平面四连杆：机架 `d = 0.052` m、曲柄 `a = 0.024` m、连杆 `b = 0.055` m、
摇杆 `c = 0.032` m。源码采用"O2 在原点、O4 在 `(0, d)`"的局部坐标系（u-v 平面），
曲柄角 `theta` 从 +u 轴起算：

```text
B = (a cos(theta), a sin(theta))              // 曲柄销
r = |O4 - B|,  O4 = (0, d)
cos(beta) = (b^2 + r^2 - c^2) / (2 b r)       // 三角形 B-A-O4 的余弦定理
phi = atan2(d - Bv, -Bu) + sign * beta        // B->A 的方向角，sign = ±1 选装配分支
A = B + b (cos(phi), sin(phi))
psi = atan2(Av - d, Au)                        // 摇杆角
```

当 `cos(beta)` 超出 [-1,1] 时返回 `null`，表示该曲柄角无法装配（机构尺寸不满足
整周回转条件时会在此暴露）。实际选用的分支、摆角范围与速度比由下一节的扫描确定。

### 5.2 分支选择与连续性

四连杆有两个装配分支（`sign = ±1`），对应"连杆在上/在下"两种构型。源码用 720 个
曲柄角采样扫描两个分支，判定标准：

1. 所有采样点均可装配，且相邻摇杆角差（解缠绕后）小于 0.6 rad，保证连续；
2. 输出端必须是**摆动**而不是整周回转：若半摆幅 ≥ π/2，评分加 100 惩罚；
3. 在通过分支中取总角行程 `sum |dpsi|` 最小者。

当前参数下选中 `sign = -1`，结果为：

| 量 | 值 |
| --- | --- |
| 摇杆中位角 `psi_0` | −3.61° |
| 摇杆半摆幅 | 52.64° |
| 摇杆全摆幅 | **105.28°**（≈1.837 rad） |
| 摇杆范围 | −56.25° … +49.03° |
| 最大速度比 `max|dpsi/dtheta|` | 1.4567 |
| 传动角范围 | 27.16° … 90.00° |

如果两个分支都无法通过连续性检查，源码退回 `psi ∈ [−0.5, 0.5]` rad 的小角度
近似，保证仿真不崩溃——这是一种"优雅降级"，正常参数下不会触发。

### 5.3 Grashof 条件与传动角

四杆机构能成为"曲柄摇杆"的条件是 Grashof 不等式：

```text
s + l <= p + q
```

其中 `s = 24` mm（最短，曲柄）、`l = 52` mm（最长，机架）、`p = 55` mm（连杆）、
`q = 32` mm（摇杆）。代入得 `24 + 52 = 76 <= 55 + 32 = 87`，满足 Grashof；
且最短杆（曲柄）与机架相邻，因此是曲柄整周回转、摇杆往复摆动的**曲柄摇杆机构**。
若把曲柄加长或机架缩短到不满足该式，机构会变成双摇杆，曲柄无法整周转动。

传动角 `mu` 是连杆与摇杆之间的夹角（取锐角），衡量力矩传递效率：`mu → 0°` 时
机构接近死点，同样的曲柄转矩只能产生很小的摇杆转矩。当前机构 `mu ∈ [27.16°, 90°]`，最小值 27.16° 出现在摇杆接近下极限附近，低于
工程上常用的 `mu_min >= 40°` 经验下限。这是为了把摇杆全摆幅做到约 105° 所做的
折中；继续增大摆幅会进一步靠近死点，传动角与关节力都会迅速恶化。若需要更高
传动效率，可增大摇杆/连杆比，但代价是扑动角减小。

### 5.4 从摇杆角到翼面扑动

翼根扑动角由摇杆角线性放大：

```text
phi_root = (psi - psi_0) * flapGain,   flapGain = 1.0
```

因此翼根铰链（尚未乘展向 `shape`）的扑动幅值为 `±(52.64° × 1.0) = ±52.64°`。但真实翼面不是
刚性平板，源码用三个展向分布描述柔性：

```text
shape(s)  = 1 + flex * (2s - 1) = 1 + 0.30*(2s - 1)      // 0.7 ... 1.3
flap(s)   = phi_root * shape(s) + dihedral * s
theta(s)  = theta_root + twist * s
chord(s)  = chordRoot + (chordTip - chordRoot) * s        // 0.400 -> 0.250（展弦比≈1.7，宽翼低速方案）
```

由此得到：

| 站位 | 展向位置 | 扑动幅值（半幅） | 弦长 | 桨距附加 |
| --- | --- | --- | --- | --- |
| 翼根 s=0 | 0 | ±36.85°（×0.7） | 0.400 m | 0° |
| 翼中 s=0.5 | 0.275 m | ±52.64°（×1.0） | 0.1875 m | +2.87° |
| 翼尖 s=1 | 0.55 m | ±71.30°（×1.3 + 上反 2.87°） | 0.250 m | +5.73° |

翼尖更大的扑动幅度、上反角与扭转梯度共同模拟真实鸟翼的"展向柔性"：翼尖在相同
曲柄相位下划出更长的弧线，配合扭转梯度形成沿展向变化的局部迎角与载荷分布。注意
这里的柔性是**运动学预设**，不是结构动力学求解——翼面不会因为气动载荷而动态变形。

左右翼的变换矩阵为镜像关系：右翼用 `A = R_phi * R_theta`，左翼用
`M A M`（`M = diag(1,1,-1)`），所有方向矢量的 z 分量取反，位置 z 也取反。这样
两翼在几何上严格对称，而各自的 `uFlap`、`uTheta` 仍是"该翼自身的速度方向"。

### 5.5 俯仰（桨距）调度：为什么由扑动角速度驱动

扑翼产生净升力的关键不是"上下扇动"本身，而是**下扑时翼面接近水平（兜风）、
上扑时翼面接近竖直（切气）**。源码用一个由扑动角速度归一化驱动的桨距角实现：

```text
dMax    = max|dpsi/dtheta| * flapGain = 1.4567
flapMax = 摇杆半摆幅 * flapGain = 0.9187 rad
nr = dFlap / dMax
np = flap / flapMax
w  = cos(featherLag) * shape(nr) + sin(featherLag) * shape(np)
theta = feather0 - featherAmp * w
```

其中 `shape(x)` 是可削顶的饱和函数：

```text
K = 2.2,  thK = tanh(K)
shape(x) = (1 - hold) * x + hold * tanh(K*x)/thK
```

- `feather0 = 0.79 rad = 45.26°`：中位桨距；
- `featherAmp = 0.79 rad`：桨距摆幅；
- `featherHold = 0.45`：削顶程度，越大越接近方波，模拟鸟类/昆虫快速翻转；
- `featherLag = 0`：纯角速度驱动；`pi/2` 则变成纯位置驱动。

当 `hold = 0.45` 时，`shape(x)` 在 `|x|` 较小时接近线性，在 `|x|` 接近 1 时被
tanh 压平；这与"下扑中段快速翻转、两端保持"的观察一致。用 tanh 而不是 `|x|^p`
是为了让导数处处有界，避免在 `x = 0` 处的奇点导致数值抖动。

当前参数下的相位关系（曲柄角 → 扑动角/桨距角）如下：

| 曲柄角 | 扑动角 | `dphi/dtheta` | 桨距角 | 状态 |
| --- | --- | --- | --- | --- |
| 0° | +8.0° | +0.761 | 15.2° | 下扑中段，接近水平 |
| 30° | +30.4° | +0.720 | 16.3° | 下扑加速 |
| 60° | +49.0° | +0.441 | 25.6° | 接近上极限 |
| 90° | +46.4° | −0.857 | 77.9° | 上扑加速，切气 |
| 120° | +6.9° | −1.344 | 88.4° | 最快上扑，刀锋 |
| 150° | −24.5° | −0.767 | 75.5° | 上扑 |
| 180° | −41.6° | −0.409 | 63.7° | 上扑后段 |
| 240° | −52.5°（下极限） | +0.040 | 43.3° | 换向 |
| 300° | −33.8° | +0.568 | 21.0° | 下扑加速 |

桨距角的工作范围为 **15.19° … 90.53°**。下扑时 `dphi/dtheta > 0` ⇒ `w > 0` ⇒
`theta` 变小（接近水平）；上扑时相反。注意下扑最快速度只有 `|dphi/dtheta| = 0.761`，
约为上扑峰值 1.4567 的一半——归一化分母取全局最大速度，因此下扑桨距最低只到 15.2°，
而不是理论上的 0°。上扑峰值处则可以完全翻到 90° 附近。这个不对称来自四连杆的
"急回"特性，是本机构真实行为，而不是简单的 ±45° 正弦。
这就是"由扑动角速度驱动"的被动扭转机制：不需要额外的伺服，仅靠机构相位就能让
翼面在正确的时间处于正确姿态。

### 5.6 冲程平面倾角如何产生推力

扑动轴不是机体 x 轴，而是绕 z 轴向前倾斜 `strokeTilt = 0.06 rad = 3.44°`：

```text
axis = (cos(strokeTilt), sin(strokeTilt), 0)
```

翼面绕该轴转动，意味着下扑行程不是纯上下，而是"向下 + 向后"；上扑是"向上 + 向前"。
由于下扑时翼面兜风（高升力/高阻力）、上扑时切气（低阻力），两个半周期的气动力
不对称，周期平均后就出现一个向前的分量——这就是**推力**。若 `strokeTilt = 0`，
下扑与上扑的 x 向冲量近似抵消，周期平均推力接近零。

在当前参数、`omega_crank = 40 rad/s`、无来流、机体静止的条件下，对整周期积分得到：

| `strokeTilt` | 周期平均 `F_x` | 周期平均 `F_y` | 说明 |
| --- | --- | --- | --- |
| −0.2 rad | −2.90 N | 4.27 N | 反向推力 |
| 0 | +0.28 N | 3.71 N | 近似对称（残余来自柔性/上反） |
| **0.06 rad** | **+1.50 N** | **3.76 N** | 设计工作点 |
| 0.18 rad | +3.48 N | 4.17 N | 更大推力/更大阻力 |
| 0.4 rad | +3.56 N | 4.47 N | 接近饱和 |

这张表是理解"倾角—推力"关系的最直接证据：升力对倾角不敏感（3.7–4.5 N），但推力
从约 0.28 N 变到 1.5 N（默认 0.06 rad）甚至 3.5 N（0.18 rad）。实际飞行中，倾角
产生的推力还要与机体阻力、姿态投影共同平衡；爬升/前飞时飞控通过俯仰姿态把升力
矢量倾斜，产生额外的水平分量。

### 5.7 差动扑动与滚转

自由飞行模式下，左右翼的扑动幅值可差动：`gR = 1 + rollTrim`、`gL = 1 - rollTrim`，
`rollTrim = 0.22 * input.roll`。差动扑动改变左右升力，产生滚转力矩。悬停辅助模式
下差动被关闭，滚转由辅助力矩控制。注意差动只缩放扑动角/角速度，不改变桨距调度，
因此是一种"低成本"的滚转操纵。

## 6. 气动模型：准定常叶素理论 + Viterna 失速后极曲线

### 6.1 叶素离散

单侧翼沿展向分成 9 段（`strips = 9`），站位取半格中心：

```text
s_i = (i + 0.5) / 9,          i = 0..8
r_i = s_i * span
dr  = span / (strips - 1) = 0.55/8 = 0.06875 m
area_i = chord(s_i) * dr
```

每个站位的代表点为 1/4 弦点（`p_local = [-0.25*chord, 0, r]`），气动力作用于此。
9 段是精度与实时性的折中：段数更多能更好捕捉展向载荷分布，但每帧计算量线性增长；
9 段已能表现翼根/翼尖的攻角差异与滚转力矩。

> 离散化说明：站位取半格中心，但 `dr` 按 `strips-1` 均分，离散总面积
> `sum chord(s_i) * dr = 0.1160` m²，比几何翼面积 `2 * 0.55 * 0.1875 = 0.20625` m²
> 的单侧 0.103125 m² 大约 12.5%。这是离散化带来的已知偏差，当前未做面积归一化；
> 它等价于把气动力整体放大同一比例，不影响趋势与配平，但做绝对升力标定时需注意。

### 6.2 局部速度与相对风

每个叶素的速度由四部分组成：

```text
v_point = v_body + omega × r + (dphi/dt) * u_flap + (dtheta/dt) * u_theta
```

- `v_body`：机体平动速度（机体系）；
- `omega × r`：机体转动在叶素处产生的线速度；
- `u_flap = axis × (A p_local)`：单位扑动角速度对应的线速度方向；
- `u_theta = R_phi * (z_hat × (R_theta p_local))`：单位桨距角速度对应的线速度方向。

相对风为风速减叶素速度：

```text
W = wind_B - v_point
W = W - (W · e_span) e_span          // 去掉展向分量，叶素理论只关心剖面内来流
V = max(|W|, 0.08)                    // 低速保护，避免除零与极曲线奇点
W_hat = W / V
alpha = atan2(W_hat · e_normal, W_hat · e_chord)
```

`V` 下限 0.08 m/s 是数值保护：在翼面换向瞬间，局部速度可能接近零，若直接代入
`q = 0.5 rho V^2` 会得到零力，且极曲线在低 Re 下本身不适用；钳位保证计算稳定。

### 6.3 翼型极曲线

**附着流段**（`|alpha| <= alpha_stall = 0.21 rad = 12.03°`）：

```text
C_L = C_l_alpha * alpha = 5.4 * alpha
C_D = C_d0 + k_ind * alpha^2 = 0.020 + 0.055 * alpha^2
```

**失速后段**采用 Viterna 平板延伸（以正迎角为例，负迎角按奇对称处理）：

```text
C_L_stall = 5.4 * 0.21 = 1.134
C_D_stall = 0.020 + 0.055 * 0.21^2 = 0.0224255
C_D_max   = cdMaxBase + cdMaxK * AR = 1.11 + 0.018 * 3.6 = 1.1748
A2 = ((C_L_stall - C_D_max sin(a_s) cos(a_s)) * sin(a_s)) / cos^2(a_s)
B2 = C_D_stall - C_D_max sin^2(a_s)
C_L = (C_D_max/2) sin(2a) + A2 cos^2(a) / sin(a)
C_D = C_D_max sin^2(a) + B2 cos^2(a)
```

代入参数得 `A2 = 0.1949`、`B2 = −0.02864`。极曲线在 `alpha_stall` 处连续：
两段在 12.03° 的 `C_L`、`C_D` 相同；到 90° 时 `C_L = 0`、`C_D = C_D_max = 1.1748`，
符合平板法向流的极限。负迎角时 `C_L` 取反、`C_D` 保持。

当前极曲线的采样值：

| 迎角 | C_L | C_D | 说明 |
| --- | --- | --- | --- |
| 0° | 0.000 | 0.0200 | 零升 |
| 5° | 0.471 | 0.0204 | 线性段 |
| 10° | 0.942 | 0.0217 | 接近失速 |
| 12.03° | 1.134 | 0.0224 | 失速峰值 |
| 15° | 0.996 | 0.0520 | 失速后升力下降、阻力上升 |
| 30° | 0.801 | 0.2722 | 深失速 |
| 45° | 0.725 | 0.5731 | 接近平板 |
| 60° | 0.565 | 0.8739 | — |
| 90° | 0.000 | 1.1748 | 平板法向 |

失速后模型的意义：扑翼在换向、强阵风、大机动时局部迎角很容易超过 12°，若继续
用线性升力会得到荒谬的大升力；Viterna 模型给出"升力下降、阻力剧增"的合理趋势，
使大迎角下的载荷与功率耗散更接近真实。

### 6.4 法向/切向力分解

直接用 `F = q S (C_L e_L + C_D e_D)` 在 `alpha → ±90°` 时会出现"升力方向"定义的
奇点。源码改用**剖面法向/切向分解**：

```text
s_c = sign(cos(alpha))
F_n = C_L cos(alpha) * s_c + C_D sin(alpha)
F_d = -C_L sin(alpha) * s_c + C_D cos(alpha)
F   = q S (F_n * e_normal + F_d * e_chord)
q   = 0.5 * rho * V^2 * S
```

其中 `F_n` 是沿翼面法向的力系数，`F_d` 是沿弦向的力系数。在 `|alpha| < 90°` 时
`F_n = C_L cos + C_D sin`、`F_d = −C_L sin + C_D cos`，等价于常规分解；`s_c` 的
作用是在负迎角时保持法向力的符号正确。该写法在任意迎角下都连续、无除零，适合
实时仿真。

### 6.5 翼面力/力矩积分

对 9 个叶素求和：

```text
F  = sum F_i
M  = sum (p_i × F_i)                       // 对质心的力矩
Q      = sum (F_i · u_flap,i)              // 广义气动力：对应扑动自由度
Q_theta= sum (F_i · u_theta,i)             // 广义气动力：对应桨距自由度
alpha_mean = sum(alpha_i * area_i) / sum(area_i)
```

`Q` 与 `Q_theta` 是"把分布气动力投影到机构自由度"的结果，后面用于计算曲柄负载
力矩。这样电机看到的是真实的气动负载，而不是人为给定的常数阻力。

### 6.6 模型边界

- **准定常**：气动力只依赖瞬时相对速度与迎角，不建模前缘涡（LEV）、动态失速延迟、
  附加质量、尾涡下洗与翼尖涡；
- **无结构动力学**：翼面弯曲/扭转是运动学预设，不随气动载荷反馈；
- **无翼间干扰**：左右翼独立积分，不建模机身处干扰；
- **无地面效应**；
- **极曲线与 Re 无关**：真实扑翼的 Re 约 10⁴–10⁵，失速特性与 Re 相关；
- **平板延伸经验性**：Viterna 系数来自风力机叶片实验，用于扑翼是工程外推。

这些简化在"实时可视化 + 趋势正确的工程仿真"范畴内是可接受的；若用于真实设计
验证，需要 CFD 或带动态失速模型的高保真气动。

## 7. 升力、推力、阻力与风的耦合

### 7.1 升力从哪来

每个叶素按其瞬时迎角产生法向力；两侧翼对称积分后，机体 y 方向的分量就是升力。
扑翼的升力不是恒定的：一个扑动周期内，下扑时迎角大、动压高，升力峰值高；上扑时
翼面切气，升力下降甚至为负。HUD 显示的"升力"是**整机 y 向气动合力**经 0.1 s 低通
后的值，因此显示的是周期平均值附近的值，而不是 10 Hz 的瞬时峰值。

### 7.2 推力从哪来

推力来自两个不对称：

1. **冲程平面倾角**（`strokeTilt`）：把扑动轴向前倾斜，使下扑带后向分量、上扑带
   前向分量；配合下扑高阻力/上扑低阻力的相位差，周期平均产生向前力；
2. **俯仰相位**（`feather0/featherAmp/featherLag/featherHold`）：保证下扑"兜风"、
   上扑"切气"。

两者共同作用，缺一不可：只有倾角而没有正确的桨距调度，上扑和下扑的阻力会抵消；
只有桨距调度而没有倾角，力矢量在 x 方向近似对称抵消。`5.6` 的表格展示了倾角从
0 到 0.06 rad（再到 0.18 rad）时周期平均推力的变化。

### 7.3 阻力从哪来

- **翼面阻力**：型阻（`C_d0`）+ 升致阻力（`k_ind alpha^2`）+ 失速后压差阻力；
- **机体阻力**：三轴二次阻力，见第 2.2 节；
- **尾翼阻力**：平尾/垂尾按相同的叶素极曲线计算；
- **诱导阻力**：本模型没有显式下洗/诱导速度场，升致阻力通过 `k_ind alpha^2` 近似，
  不随展弦比动态变化。

前飞时，机体速度改变翼面相对风，降低有效迎角；升力先随速度增加，超过配平点后
需要减小桨距/扑动幅值，否则会爬升。阻力随速度平方增长，最终与推力平衡决定最大
平飞速度。

### 7.4 风与阵风

世界风速由三部分构成：

```text
wind_base = speed * (cos(dir), 0, sin(dir))         // dir 为水平面角度
gust      = speed * gust_ratio * (多频正弦叠加)
wind      = wind_base + gust
```

阵风分量由 6 个不同频率的正弦叠加（2.31、7.7、3.7、9.1、5.3、11.3 rad/s），
纵向幅度为 base 的 0.6/0.4 组合，横向减半。这样既能产生低频"风推"，也能产生
高频"抖动"。风进入模型后只通过相对风 `W = wind_B − v_point` 影响叶素迎角与动压，
因此风对升力、推力、阻力、电机负载是同时作用的：

- 逆风/上升气流 → 相对风速增大 → 升力与阻力同时增大 → 电流/功率上升；
- 顺风/下沉气流 → 相对风速减小 → 升力下降 → 飞控加大油门；
- 横向阵风 → 左右翼相对风不对称 → 滚转力矩 → 需要副翼/差动扑动修正。

`wind.turb = 0.35` 是预留的湍流强度参数；当前 `updateWind` 用 `gust` 生成阵风，
湍流项未单独使用（见第 12 节）。

### 7.5 耦合环路

各物理量不是单向链条，而是一个闭环：

```text
油门 D ──> 母线电压/电流 I ──> 电机转矩 T_m ──> 曲柄转速 omega_crank
   ^                                                  │
   │                                                  v
   │                                     扑动角速度 dphi/dt
   │                                                  │
   │                                                  v
   │                                     叶素相对风 V、迎角 alpha
   │                                                  │
   │                                                  v
   │                                     气动力 F、广义力 Q、Q_theta
   │                                                  │
   │                    ┌─────────────────────────────┴──────────────┐
   │                    v                                            v
   │            机体六自由度运动                            曲柄负载力矩 tau_load
   │                    │                                            │
   │                    v                                            v
   │            相对风/姿态变化                              电机电流 I（反馈）
   │                    │                                            │
   └────────────────────┴────────────── 电池电压塌陷 <─────────────┘
```

关键反馈有三条：

1. **气动负载 → 电流**：`tau_load = -(Q dphi/dtheta + Q_theta dtheta/dtheta)`，
   转速越高、迎角越大，负载越大，电流越大；
2. **电流 → 母线电压**：`V_bus = V_open − I R_pack`，大电流导致电压下降，限制
   可用功率；
3. **机体运动 → 相对风 → 气动力**：速度/姿态改变叶素来流，进而改变升力、推力与
   负载，形成"飞行动力学—气动—电机"的闭环。

悬停配平就是让周期平均升力等于重力（`L/W ≈ 1`），同时推力与阻力平衡、力矩平衡。
由于扑动是周期性的，严格配平应对一个周期做平均；HUD 的 L/W 是低通后的近似值。

### 7.6 尾翼与操纵

平尾/垂尾用与机翼相同的极曲线与法向/切向分解计算，但作为单块气动面：

| 面 | 面积 | 位置（机体系） | 操纵 |
| --- | --- | --- | --- |
| 平尾 HT | 0.021 m² | (−0.34, 0.01, 0) | 升降舵偏转 ±0.38 rad，产生俯仰力矩 |
| 垂尾 VT | 0.014 m² | (−0.34, 0.05, 0) | 方向舵偏转 ±0.34 rad，产生偏航力矩 |

尾翼力臂 0.34 m 直接放大操纵力矩；在悬停辅助模式下，尾翼仍参与气动，但姿态主要由
辅助力矩稳定。自由飞行模式下，升降舵/方向舵的偏转由键盘输入映射（见 README）。

## 8. 能量流与功率守恒

### 8.1 能量链

```text
电池化学能
  └─> 母线电功率 P_elec = V_bus * I
        ├─> 铜损/开关损（热）
        └─> 电机轴机械功率 P_mech = T_m * omega_m
              ├─> 齿轮/轴承损失（1 - eta = 14%）
              └─> 曲柄机械功率 P_crank = eta * P_mech
                    ├─> 机构摩擦（粘性 + 库仑）
                    ├─> 翼面气动功率（升力/推力/阻力做的功 + 尾涡耗散）
                    └─> 翼面/机构动能（周期性存储与释放，周期平均≈0）
```

### 8.2 功率定义

源码中的定义为：

```text
P_elec = V_bus * I
P_mech = T_m * omega_m = K_t * I * omega_m = emf * I
eta_motor = clamp(P_mech / P_elec, -0.2, 1)
P_aero = |(Q * dphi/dtheta + Q_theta * dtheta/dtheta) * omega_crank|
P_crank,net = P_mech * eta_gear - P_friction
```

在 `I > 0` 时，由 `P_elec − P_mech = I(V_bus − emf)` 可见电-机差额与电流、反电动势
直接相关。齿轮箱效率 0.86 只作用于机械侧，不进入电机效率；因此 HUD 的"电机效率"
不含减速箱损失，整机效率还要再乘 0.86（以及气动效率）。

### 8.3 损耗明细

| 损耗 | 模型 | 量级（20 A 时） |
| --- | --- | --- |
| 电机铜损（热模型口径） | `0.75 I^2 R_phase` | 27.0 W |
| 减速传动（同步带/齿轮）与轴承 | `(1 − 0.86) P_mech` | 约为机械功率的 14% |
| 曲柄摩擦 | `b omega + f`，`b = 0.004`、`f = 0.020` | 40 rad/s 时约 7.2 W |
| 气动耗散 | 叶素阻力做功 | 与升力/速度相关 |

### 8.4 示例工作点（ω_crank = 40 rad/s）

在无来流、机体静止、默认 `strokeTilt = 0.06` 的条件下，由源码模型积分得到
（周期平均）：

- 升力 ≈ 3.755 N，L/W ≈ 0.957（重力 3.924 N）；
- 推力 ≈ 1.503 N；
- 气动负载功率 ≈ 50.39 W（即 `tau_load * omega_crank` 的周期平均）；
- 曲柄负载力矩 ≈ 1.260 N·m。

计入曲柄摩擦 `0.004*40 + 0.020 = 0.180` N·m 后，所需曲柄驱动转矩约 1.440 N·m，
对应电机轴转矩 `1.440/(26*0.86) = 0.0644` N·m，相电流约 `0.0644/K_t = 9.44` A，
电机轴机械功率约 `0.0644 * 1040 = 66.96` W。此时反电动势约
`1040/146.6 = 7.094` V，母线电压约 `11.1 − 9.44*0.028 = 10.84` V；占空比约
`(7.094 + 9.44*0.09)/10.84 ≈ 0.733`。这组数字说明：**40 rad/s 的扑动约需 0.73
油门、9.4 A 电流、约 67 W 机械功率**，与 900 mAh 电池的 24 A 峰值能力相比有合理
裕度，但持续大电流会触发 `3.5` 的温升限制。

按源码口径 `P_elec = V_bus I` 计算，电功率约 102.3 W、电机效率约 65.5%；若按
占空比平均的母线电流 `D I` 计算，电功率约 75.0 W，与机械功率 + 铜损更接近。
这一差异就是 `8.5` 要说明的口径问题。

> 上述数值是"给定工况下的示例"，会随 config 参数与飞行状态变化；请以实际 HUD 与
> `tests/tune.mjs` 的输出为准。

### 8.5 实现口径与简化

为便于读者核对，这里明确说明源码中几处"看起来像但不完全等同"的功率口径：

1. **电功率按母线电压×相电流统计**：`P_elec = V_bus * I`。严格按 PWM 平均，母线
   电流应为 `D * I`（相电流的平均值乘以占空比），因此部分油门时该口径会高估电功率、
   低估电机效率。这是模型简化，不影响"电功率 ≥ 机械功率"的定性结论；
2. **热损耗系数 0.75**：`P_loss = 0.75 I^2 R` 是对六步换向两相导通损耗的工程近似，
   与电气方程中的 `I^2 R` 有约 25% 差异；因此温度模型与电功率账本不完全闭合；
3. **回馈限制**：电流下限 `-0.35 I_lim` 限制了下坡/减速时的能量回灌；模型不建模
   ESC 的制动斩波与电池充电接受能力；
4. **机械动能**：翼面与机构在半个周期内存储/释放动能，瞬时 `P_crank` 可能为负；
   周期平均才等于气动耗散 + 摩擦。

### 8.6 续航估算

`flightSeconds = (0.9 * SOC) / max(I, 0.05) * 3600`。这是一个"当前电流恒定"的
保守估算，未考虑电压下降导致的功率变化、油门调整与电池放电曲线。实际续航应以
能量积分（`∫ V_bus I dt`）为准。

## 11. 数值实现与稳定性

### 11.1 时间步进

物理子步固定为 `SUBSTEP = 1/240 s ≈ 4.167 ms`。主循环以固定步长累加，与渲染帧率
解耦（渲染可以 60 FPS，物理仍按 240 Hz 推进）。固定步长的好处是可重复、便于调参；
坏处是帧率波动时需要"追帧"，`src/main.js` 把每帧最多追赶的子步数限制为 16，
防止卡顿后出现"越算越慢"的雪崩。

### 11.2 显式积分

曲柄转速用显式 Euler：

```text
omega_crank <- omega_crank + (T_drive - T_res)/J_eq * dt
```

其中 `T_drive = eta G K_t I`、`T_res = tau_load + 粘性 + 库仑`。dt 足够小（4.17 ms），
且 `J_eq` 最小约 1e-2 量级，显式积分稳定。实现中还有三道保护：

1. `omega_crank < 0` 时钳到 0（不允许曲柄反转）；
2. `omega_crank > wMax` 时钳到空载转速的 1.02 倍；
3. 电机负载力矩取本步开始时的气动广义力（一步滞后），对 240 Hz 可以接受。

### 11.3 角度与数值保护

- 曲柄角每步回绕到 `[0, 2π)`，避免浮点精度累积；
- 叶素相对速度下限 0.08 m/s，避免零速除零；
- 极曲线中 `cos²` 分母、`sin` 分母都有保护（`max(..., 1e-6)`、`max(cd, 0.005)`）；
- 四连杆无解时返回 `null`，控制量退化为 0 而不是 NaN；
- 四连杆分支扫描失败时退回小角度近似；
- 地面穿透时位置钳到 0.06 m 并衰减反弹；
- 电机温度、SOC 均由积分得到，但没有硬钳位（温度可超过 `tempMax`），HUD 只做显示。

### 11.4 可重复性与调参

所有物理参数集中在 `src/config.js`，修改后刷新页面即可生效（无构建步骤）。调参
建议顺序：先确认四连杆能整周回转（看 `link.degenerate`），再调 `flapGain` 与
`feather*` 使 L/W 在 0.75–0.95 油门达到 1 左右，最后调电机 KV/减速比/电池电压
匹配功率与温升。

## 12. 适用边界与扩展方向

### 12.1 当前模型适合回答的问题

- 扑动频率、桨距相位、冲程倾角对升力/推力/功率的趋势影响；
- 电机 KV、减速比、电池电压、限流对可用扑动频率与续航的影响；
- 四连杆尺寸对摆角、传动角、速度比的影响；
- 风/阵风对升力、姿态、电流的扰动趋势；
- 控制增益与飞行模式的定性手感。

### 12.2 不适合回答的问题

- 绝对升力/功率的精确预测（无 CFD、无动态失速、无真实翼型数据）；
- 结构强度、翼面气动弹性、疲劳寿命；
- 电机电磁设计、ESC 开关损耗、电池老化；
- 高保真飞行品质（Bode 图、操纵导数）。

### 12.3 可能的扩展

1. **非定常气动**：加入 Wagner 函数/Leishman-Beddoes 动态失速、前缘涡模型；
2. **结构动力学**：把翼面弯曲/扭转作为弹性自由度，与气动耦合；
3. **诱导速度场**：用动量理论或自由尾迹修正下洗，得到随速度变化的诱导阻力；
4. **电感与换向细节**：加入 `L di/dt`、反电动势谐波、六步换向的瞬时转矩脉动；
5. **电池模型**：OCV-SOC 曲线、温度相关内阻、老化；
6. **风场**：Dryden/von Kármán 连续湍流、切变风、热气流；
7. **控制**：从 PD 增稳升级为角速率/姿态串级控制，加入轨迹跟踪。

## 附录 A：四连杆速度比的解析式

对闭环复数方程

```text
a e^{i theta} + b e^{i phi} = i d + c e^{i psi}
```

两边对 `theta` 求导，并利用 `phi` 的虚部消去 `dphi/dtheta`，可得

```text
dpsi/dtheta = a sin(theta - phi) / (c sin(psi - phi))
```

源码没有直接使用该解析式，而是用中心差分（`h = 4e-4`）求 `dpsi/dtheta` 与
`d²psi/dtheta²`；两者在正常参数下一致。使用差分的优点是无需处理分母为零的特殊
位置，且与 `fourBar` 的数值解严格配套；缺点是步长过小会有舍入误差，过大则平滑掉
高速段的峰值。`4e-4` rad 相对曲柄整周 2π 约 6.4e-5，是折中值。

## 附录 B：Viterna 系数的连续性

在 `alpha = alpha_stall` 处，附着流段给出 `(C_L_s, C_D_s)`；失速后段要求同一组
值，由此解出 `A2`、`B2`：

```text
C_L_s = (C_D_max/2) sin(2a_s) + A2 cos^2(a_s)/sin(a_s)
C_D_s = C_D_max sin^2(a_s) + B2 cos^2(a_s)
```

整理即得源码中的两式。该构造保证极曲线在失速点连续，且 `alpha = 90°` 时退化为
平板法向流（`C_L = 0, C_D = C_D_max`）。负迎角通过奇对称 `C_L(-a) = -C_L(a)`、
偶对称 `C_D(-a) = C_D(a)` 处理，源码用 `sign` 与 `|alpha|` 实现。
