## 0. 问题定义（可量化）

| 现象 | 指标 | 当前基线（remote bench, 8s 闭环） |
|---|---|---|
| 升力是"脉冲"不是"稳态" | 升力 std / mean（脉动指数） | **117 %**，峰峰 13.96 N（均值 3.93 N） |
| 上扑可能产生向下力 | 上扑净冲量 N·s/周期 | **+0.018**（接近 0，某些相位为负） |
| 机体被周期性冲击 | 高度 std / 俯仰 RMS | 0.069 m / 1.46° |
| 控制不知道自身参数 | 质量/惯量/推力系数估计误差 | 目前为**常数硬编码**（0 感知） |

**结论**：脉动来自扑动本身（单冲程做功），仅靠"调气动参数"最多把脉动从 117% 降到 ~95%（18 组扫描已证），
必须引入 **(A) 相位/机构层面的对置扑动** + **(B) 有模型感知识别的控制器**。

## 1. 关键发现（已实测，直接决定方案）

### 1.1 对置扑动可以把升力脉动砍掉一半以上
左右翼相位差 90°/180° 的静态气动积分（同一均值升力 4.15 N）：

| 左右相位差 | 升力 std | 脉动 | 峰峰 |
|---|---|---|---|
| 0°（现状，同相） | 5.10 N | 123 % | 14.4 N |
| 90° | 3.32 N | 80 % | 9.1 N |
| **180°（对置）** | **2.02 N** | **49 %** | **6.0 N** |

→ 相当于"单缸"变"双缸"：两个升力脉冲错开半个周期。代价是滚转力矩出现同频交变（均值 0，靠惯量滤波 + 控制器抑制）。
机构实现：同一曲柄轴上放两个相位差 180° 的曲柄销，分别驱动左右摇臂（经典对置气缸结构），改动局限在曲柄盘。

### 1.2 上扑"零负力"可以做到，但要付功率代价
18 组参数扫描（fold × featherHold × featherLag）：上扑冲量可在 **−0.035 ~ +0.231 N·s** 之间调；
取折中"fold=0.85 / hold=0.45 / lag=0"→ 上扑冲量 +0.014、俯仰 RMS 0.90°、功率 63 W。
lag=−0.6 时上扑变负（−0.03）——即"相位错了就会拍到空气"，这正好说明**相位是可控变量**。

## 2. 分阶段计划

### Phase 0 · 远程实验台（已完成 ✅）
- 把纯 ESM 的物理/控制器做成 headless 包，rsync 到 `/data/projects/orni-x`，用 `/tmp/node20` 直接跑（无需浏览器）。
- 产出：`tools/bench.mjs`（单例指标）、`tools/sweep.mjs`（参数网格）、`tools/phase.mjs`（相位差验证）。
- 性能：**8 s 闭环 = 121 ms/核**（≈66× 实时），4 核可并行；18 组扫描 2.1 s。
- 验收：指标与本地逐位一致（确定性仿真）。

### Phase 1 · 对置扑动 + 上扑整形（机构 + 气动，1–2 天）
1. **左右反相**：`kin.state(crank + π, …)` 应用到左翼（物理 + 网格 + 机构可视化两曲柄销 180°）。
2. **上扑约束**：参数优化（远程批量）使 `upImpulse ≥ +0.02 N·s` 且 `pitchRms < 1.5°`、功率增量 < 5%。
3. 指标验收：脉动 ≤ 60%，高度 std ≤ 0.03 m，俯仰 RMS ≤ 1.0°，升重比 1.0 ± 0.05。
4. 风险：反相后滚转交变力矩（需量化）；机构可视化要同步改（曲柄盘、连杆两侧）。

### Phase 2 · 有"自身感知"的控制器（2–3 天）
1. **相位锁定观测器**：用扑动相位 φ + 机体加速度，提取"每冲程平均推力/力矩"与"脉动力幅值"。
2. **在线辨识**：RLS/EKF 估计质量、z 轴惯量、推力系数、上扑残差力（可观测性从俯仰/升沉响应里来）。
   输出给控制器的前馈项 = `m̂·g + 脉动前馈(φ)`，即"知道自己多重、知道自己每扑一下能产生多少力"。
3. **控制结构**：
   - 内环 1 kHz：姿态角速率 + 相位前馈（用相位平均力表，见 bench 的 phaseLift 24-bin）；
   - 中环 100 Hz：姿态角 PD + 扑动频率陷波（notch @ f_flap）+ 积分抗饱和；
   - 外环 20 Hz：高度/水平速度 → 期望姿态与油门。
4. 验收（消融对比）：脉动 117%→≤50%（结合 Phase 1）、高度 std ≤ 0.02 m、俯仰 RMS ≤ 0.8°、
   质量偏置 +20% 时定高误差 < 3 cm 且 30 s 内收敛（证明"感知"生效）。

### Phase 3 · 果蝇脑（复用 drone-war，2 天）
- **已具备**：`px4sim:/opt/dronewar/pilot_node.cjs`（748 神经元冻结 flycore + readout，66 KB，node20 可跑），
  接口：`{"state":{position,velocity,rotation,angularVelocity},"aim":{bearing,range}}` → `{roll,pitch,yaw,alt}`。
- **接入**：flyPilot(30 Hz) 输出期望姿态/高度 → Phase 2 的内环 → 扑翼 plant（不再走 PX4，因为 PX4 的机型是四旋翼）。
- **适配**：扑翼的相位滞后比四旋翼大 → 加超前补偿 + 输出缩放；必要时开 **online readout**（dronewar 原生有 A/B 训练）在我们的 plant 里继续学。
- 验收：闭环定高悬停 ≥ 60 s 不坠、跟踪目标点 RMS < 0.5 m；与经典控制器做对照表。

### Phase 4 · 可视化/录制（可选）
- `node20 + tools/bench` 出数据；要"看得见"时用 drone-war 现成管线：Xorg :1 + `ffmpeg x11grab`；
  若必须在 Gazebo 里飞：PX4 已带 `libLiftDragPlugin.so`，可给扑翼模型加 LiftDrag 插件（工作量大，暂不默认）。

## 4. 风险与决策点
- **反相扑动的滚转交变**：需在 Phase 1 量化，若不可接受则退回"同相 + 控制抑制"。
- **果蝇脑是四旋翼式训练**：直接接扑翼可能不稳；先内环补偿，再考虑 readout 再训练（dronewar 有 A/B 代码）。
- **不引入 Gazebo 扑翼气动**：现成 PX4 SITL 没有扑翼模型，自研 JS 物理更准且更快；Gazebo 只用于出视频。

## 6. 执行结果（2026-10-28 更新）

### Phase 1 ✅ 对置扑动已实现并验证
- 物理：左右翼独立曲柄相位 `cfg.phaseDeg`（0–180°），每翼独立折算曲柄负载；UI 有"左右相位差"滑杆。
- 机构：曲柄盘改为**双曲柄销**（相差 phaseDeg）、两根连杆、左右两套摇臂与翼根接头。
- 实测（远程 bench，12–14 s 闭环）：

| 指标 | 同相 + 经典PD（改前） | 对置 + 自适应（改后） |
|---|---|---|
| 升力脉动 std/mean | 117 % | **45 %** |
| 升力峰峰 | 14.0 N | **5.7 N** |
| **最小瞬时升力** | **−0.36 N（每周期被压下去）** | **+1.29 N（永不为负）** |
| 俯仰 RMS | 1.30° | 1.69°（对置+经典PD 为 4.74°） |
| 高度 std | 0.054 m | 0.069 m |
| 功率 | 63 W | 58 W |

### Phase 2 ✅ 自适应飞控 v1（辨识 + 前馈 + 陷波）
`src/control/adaptive.js`：
1. **垂向 RLS**（整周期平均）估 `a_y = b·u − g` → 悬停油门 `u_h = g/b`；
2. **自适应配平**：加速度误差慢积分 → 在线学出"吊住自重所需油门"（HUD "悬停油门估计" = 86%）；
3. **俯仰力矩相位前馈**（ILC，32 相位 bin，提前 2 bin 补偿时延）→ 抵消对置扑动的周期性俯仰扰动；
4. **扑动频率陷波**（biquad notch @ f_flap）在阻尼通道；
5. 鲁棒性：质量 +30% / 惯量 +40% 时仍稳定收敛（控制器不依赖真实质量参数）。

*注：油门通道的 ILC 已实现但默认关闭（ilcOn=false）——高速调制电机需要带宽，留待与电机匹配后再启用。*

## 7. 训练（2026-10-28，在 192.168.3.5 上）

### 7.1 任务与环境
- **环境**：风洞式「平移锁定」（只保留转动动力学），条件随机化：空速 0–12 m/s、风向随机、姿态指令 ±26°/±20°、惯量 ×0.75–1.35、质量 ×0.85–1.15、油门 0.70–1.00。
- **目标**：保持姿态稳定，cost = 4·(俯仰RMS+滚转RMS) + 0.35·角速率RMS + 失败罚项。
- **策略**：18 维参数化控制器（姿态 PD、积分、空速调度、陷波 Q、相位前馈增益/学习率/超前 bin、偏航增益）。
- **优化器**：自研紧凑 CMA-ES，pop 14，40 代，4 个 seed 并行（192.168.3.5，4 核）。

### 7.2 结果（留出网格：5 空速 × 3 幅值 × 3 惯量 = 45 条件，每例 8 s）

| 指标 | 手调默认 | 训练后 | 变化 |
|---|---|---|---|
| 俯仰 RMS（全包线） | 1.85° | **1.19°** | **−36 %** |
| 滚转 RMS | 3.48° | 3.53° | ±0 |
| 平均代价 | 1.598 | **1.425** | −11 % |
| 失败数 | 0/45 | 0/45 | — |

按空速看俯仰 RMS：0 m/s 0.58°→**0.17°**，3 m/s 1.41°→**0.32°**，6 m/s 1.56°→**0.43°**，12 m/s 2.69°→**0.19°**；9 m/s 是唯一变差点（3.01°→4.82°）。

### 7.3 已集成
- src/config.js 的 trainedPolicy；UI「飞控」三选一：经典 PD / 自适应 / **训练后**。
- 应用内悬停实测：俯仰 RMS 1.31° → **0.93°**，滚转/高度持平。
- 复现：train/run.mjs 训练 → train/pick.mjs 选优 → train/evalgrid.mjs 评估；单种子 40 代约 75 s，4 进程并行跑满 4 核。

### 7.4 已知短板
1. **滚转没进步**（3.5°）：对置扑动的滚转交变力矩需要专门的相位前馈，训练把 ffGainR 压到 0.09（说明现有滚转前馈的相位/超前量不对）；下一步把滚转 lead 单独参数化。
2. 9 m/s 离群：训练分布中高速+大幅值样本不足，需按空速分层采样。
3. 4 个 seed 里 3 个在留出网格上明显过拟合（训练 cost 更低、网格更差），下一步用固定验证集 + 早停替代纯域随机化。
